# One Page สถานการณ์น้ำ สชป.10 — V3

ปรับ Web App ให้ผลลัพธ์เป็น One Page 16:9 ตามภาพอ้างอิงล่าสุด โดยตัดส่วนอุทกภัย/แผนที่ออก และจัดพื้นที่ใหม่เต็มหน้าเป็น 7 ส่วน:

01 สถานการณ์ฝน
02 อ่างเก็บน้ำ
03 สถานการณ์น้ำท่า
04 ผลการเพาะปลูก
05 แผน-ผลการจัดสรรน้ำ
06 การให้ความช่วยเหลือ
07 ผลการดำเนินการกำจัดวัชพืช

หน่วยผลการเพาะปลูกเปลี่ยนเป็น “หน่วย : ไร่”

## วิธีใช้
เปิด index.html ด้วย Chrome/Edge แล้วกรอกข้อมูลด้านซ้าย ระบบจะอัปเดต One Page ด้านขวาทันที

## API ฝน
ตั้ง API Proxy URL ในแท็บ API ฝน โดย endpoint ควรคืนค่า JSON แบบ:
{"rows":[{"province":"เพชรบูรณ์","station":"บ้านวังขอน","rainMax":40,"rainAccum":957.84,"normalCompare":"+10.10"}]}
หรือ rows เป็น array ของ array ก็ได้

แนะนำให้เก็บ token ไว้ฝั่ง backend ไม่ฝัง secret ใน frontend production
